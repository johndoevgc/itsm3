All AI capabilities use Azure OpenAI Service with automatic failover across three model tiers for resilience and cost optimization. v3.0 adds AI Governance, Budget Control, Automation Rules, and comprehensive audit logging.

Model Architecture

TierModelUse CasesFallback
Primarygpt-5.4-proComplex triage, risk analysis, KB generation, anomaly detection→ mini
Secondarygpt-5.4-miniStandard triage, chat, summaries, semantic search→ nano
Tertiarygpt-5.4-nanoQuick classification, tagging, simple lookups→ manual

Failover is automatic — if primary times out or errors, the system cascades to the next tier. Uses max_completion_tokens parameter (not max_tokens).

AI Features

1. Intelligent Triage

Auto-classify incoming tickets by category, priority, and assignment group. Confidence-based: auto-apply at 85%+, suggest at 70%+.

POST /api/ai/triage

2. Resolution Suggestion

Analyze ticket context and KB to suggest resolutions with confidence scoring.

POST /api/ai/suggest-resolution

3. Virtual Agent (Chatbot)

Conversational AI with session management, context memory, and escalation to human agents.

POST /api/ai/chat — Sessions stored in ai_chat_sessions

4. KB Auto-Generation

Generate knowledge base articles from resolved incidents. AI drafts stored for review before publishing.

POST /api/ai/generate-kb — Drafts in ai_kb_drafts

5. Change Risk Assessment

AI evaluates change requests and assigns risk scores based on scope, impact, and historical data.

POST /api/ai/risk-assessment

6. Recurring Incident Detection

Pattern recognition across incidents to identify recurring issues and suggest problem records.

GET /api/ai/recurring-patterns — Patterns in ai_patterns

7. Semantic Search

Natural language search across KB articles and tickets. Goes beyond keyword matching.

POST /api/ai/semantic-search

8. Capacity Forecasting

Predict future resource needs based on historical ticket volume, seasonal trends, and growth patterns.

GET /api/ai/capacity-forecast

9. Anomaly Detection

Detect unusual patterns in ticket volume, response times, and SLA metrics. Auto-generates alerts.

GET /api/ai/anomaly-detect

10. Trend Forecasting

Predict future SLA performance, ticket volumes, and resource utilization.

GET /api/ai/forecast

11. Daily Briefing

AI-generated daily operations summary for managers, covering open items, SLA status, and action items.

POST /api/ai/daily-briefing — Stored in ai_briefings

12. AI Learning & Feedback

Continuous improvement through agent feedback on AI suggestions. Tracks accuracy and adapts.

POST /api/ai/feedback — Feedback in ai_learning_feedback

AI Performance Dashboard

Monitor AI health via the in-app AI Performance Dashboard or API endpoints:

  • GET /api/ai/performance — accuracy, response times, usage by tier
  • GET /api/ai/learning/metrics — learning trends, feedback analysis
  • GET /api/ai/thresholds — current confidence thresholds
  • POST /api/ai/thresholds — adjust thresholds
