Workflow Automation Engine (v3.1)

Scheduled Task Runner (10.1)

Cron-like recurring task execution engine. Tasks are registered at server startup and evaluated every 15-minute cycle. Stats are included in the workflow engine's getStats() response.

MethodInternal APIDescription
registerScheduledTask(id, opts)Server-sideRegister a recurring task: { name, intervalMs, handler, enabled }
runScheduledTasks()Auto (each cycle)Execute all due tasks — tracks runCount, errors, lastRun, nextRun
getScheduledTaskStats()Server-sideReturns array of task stats: id, name, enabled, intervalMin, lastRun, nextRun, runCount, errors

Multi-tier Escalation Chain (10.2)

Automatic escalation of Sev-A/B incidents through configurable tiers. Sev-B thresholds are doubled. Supports in-app, email, and SMS notification channels. Escalation events are logged to the escalation_log collection.

ConfigDefaultDescription
Level 115 min (Sev-A) / 30 min (Sev-B)Notify: engineer — Channel: in-app
Level 230 min / 60 minNotify: team_lead, senior_engineer — Channel: in-app + email
Level 360 min / 120 minNotify: manager, director — Channel: in-app + email

Skill-based Auto-Assignment (10.3)

Automatically assigns unassigned incidents to engineers based on incident category and current workload. The engineer with the lowest active ticket count for a matching skill category is selected.

Change Approval Pipeline (10.4)

3-stage change approval workflow evaluated each cycle. Maintains full approvalHistory audit trail on each change record.

StageCriteriaAction
Auto-ApproveStandard + Low/None riskAutomatically approved, approvalStage: "auto"
Manager ApprovalNormal or Standard + Medium/High riskStatus set to "Pending Approval", notification sent
CAB ReviewEmergency changesFlagged for CAB review, critical notification sent

Security & Observability (v3.1)

Phase 8: Security Hardening

FeatureDetails
RBAC EnforcementAll Zendesk routes enforce role-based access (12 roles × 14 permission dimensions)
Webhook HMAC-SHA256X-Zendesk-Webhook-Signature + X-Zendesk-Webhook-Signature-Timestamp verified with timing-safe comparison. Env: ZENDESK_WEBHOOK_SECRET
Input ValidationticketId, status, priority validated on all write endpoints. Max payload: 500KB (webhooks), 1MB (standard)

Phase 9: Observability & Reliability

FeatureDetails

Correlation IDsX-Correlation-Id header on every HTTP response for request tracing
