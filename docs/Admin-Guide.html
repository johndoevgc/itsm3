2. AI Configuration

Secondarygpt-5.4-miniStandard triage, chat, summaries
Tertiarygpt-5.4-nanoClassification, quick lookups

Configure via Admin Settings → OpenAI, or POST /api/settings/openai.

2.2 Confidence Thresholds

Adjustable at GET /api/ai/thresholds:

  • Auto-Apply: 70% (suggest) / 85% (auto-apply)
  • SLA Risk: 70% — flag at-risk tickets
  • Auto-Resolve: 60% — resolve with known solutions

3. Integration Setup

3.1 Zendesk

  1. Go to Admin Settings → Integrations → Zendesk
  2. Enter subdomain, admin email, and API token
  3. Test connection with GET /api/zendesk/me
  4. Run initial import: POST /api/zendesk/full-import
  5. Enable webhook for real-time sync

3.2 Microsoft Entra ID

  1. Register app in Azure Portal → Entra ID → App Registrations
  2. Add redirect URI: https://vgc-itsm1-app.azurewebsites.net
  3. Upload PFX certificate or create client secret
  4. Grant API permissions: User.Read.All, Group.Read.All, Mail.Send
  5. Set environment variables

3.3 Microsoft Teams

  1. Create Incoming Webhook in your Teams channel
  2. Copy webhook URL
  3. Add via POST /api/db/teams_webhooks
  4. Test: POST /api/integrations/teams/webhook with test message

3.4 SolarWinds / N-able

Configure API URL and credentials in Admin Settings → SolarWinds. Test with GET /api/solarwinds/test.

4. SLA Configuration

4.1 Business Hours

Default: Monday–Friday, 09:00–18:00 SGT. Create custom calendars via POST /api/sla/calendar for holidays and 24/7 services.

4.2 Severity Targets

Modify via POST /api/sla/config or Admin Settings → SLA.

4.3 Change Freeze Windows

Create freeze periods via POST /api/changes/freeze-window. Changes submitted during freeze are automatically rejected.

5. Deployment

5.1 Build

npx vite build                    # Frontend → dist/
cp dist/* deploy/                 # Copy to deploy folder
cp dist/assets/* deploy/assets/   # Copy JS bundles

5.2 Deploy to Azure

Upload via Kudu VFS API:

# Upload server.js
PUT https://vgc-itsm1-app.scm.azurewebsites.net/api/vfs/site/wwwroot/server.js

# Upload index.html
PUT https://vgc-itsm1-app.scm.azurewebsites.net/api/vfs/site/wwwroot/index.html

# Upload JS bundles
PUT https://vgc-itsm1-app.scm.azurewebsites.net/api/vfs/site/wwwroot/assets/{bundle}.js

# Restart
az webapp restart --name vgc-itsm1-app --resource-group vgc-itsm-1-RG
⚠️ Always delete old JS bundles from /wwwroot/assets/ before uploading new ones. Delete any stale dist/ folder on Azure — server.js prefers it over root.

5.3 Verify

GET https://vgc-itsm1-app.azurewebsites.net/api/health
GET https://vgc-itsm1-app.azurewebsites.net/api/health/deep

7. Database Maintenance

  • Stats: GET /api/db-stats — record counts per collection
  • Clean & Seed: POST /api/db-clean-seed — reset to demo data (destructive!)
  • Cache: POST /api/cache/clear — flush in-memory cache
  • Audit Integrity: GET /api/audit/verify-integrity — verify audit log hasn't been tampered
⚠️ db-clean-seed deletes ALL production data. Use only in dev/staging.
