Physical Tables

TableColumnsPurpose

audit_logid (AUTO PK), action, collection, record_id, user, details (JSON), timestampImmutable audit trail for all mutations

Each record in itsm_data is a JSON document identified by collection + id. The data column stores the full document as JSON.
