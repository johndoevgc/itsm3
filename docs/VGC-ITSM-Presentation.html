Executive Summary

VGC-ITSM is a comprehensive, AI-powered IT Service Management platform built on Microsoft Azure. It unifies incident management, service requests, asset tracking, and knowledge management into a single, intelligent platform.

Powered by Azure OpenAI (GPT-5.4-nano), the platform provides automated triage, intelligent escalation, predictive analytics, and self-healing capabilities — reducing mean time to resolution and improving service quality.

Fully PDPA compliant with enterprise-grade security via Microsoft Entra ID single sign-on with MFA enforcement.
