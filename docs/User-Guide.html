3. Tickets Module

3.1 Ticket Types

IncidentincidentsUnplanned service interruptions

3.2 Work Logs Phase 1

Track time spent on incidents. Add work logs with duration, notes, and work type. Available on the ticket detail panel under "Work Logs" tab.

3.3 Known Errors Phase 1

Document known errors with workarounds. Link known errors to incidents for faster resolution. Accessible from Tickets → Known Errors sub-tab.

3.4 SLA Pause/Resume Phase 1

Pause SLA timers when waiting for customer response. Resume when communication restarts. Available on ticket detail → SLA section.

3.5 Merge Duplicates

AI detects duplicate incidents. Review and merge from Tickets → Duplicates view. Merged tickets retain all work logs and comments.

3.6 Bulk Operations Phase 5

Select multiple tickets → Bulk Update (change status, priority, assignee) or Bulk Close. Available from the ticket list toolbar.

3.7 Ticket Templates Phase 5

Create reusable ticket templates for common incident types. Select template when creating new ticket to pre-fill fields.

3.8 Saved Filters Phase 5

Save frequently used filter combinations. Quick-apply from the filter bar dropdown.

5. Knowledge Portal

Browse, search, and contribute knowledge articles. AI-powered semantic search finds relevant articles even with different wording.

Features

  • Full-text and semantic search
  • Article versioning with history
  • AI auto-generation from resolved incidents
  • KB gap analysis — identifies undocumented topics
  • Correction workflow for inaccurate articles
  • Document upload (PDF, Word, text)

Manage customer records, view ticket history per customer, track satisfaction scores. Syncs with Zendesk organizations when connected.

10. AI Assist

10.1 AI Chat

Conversational AI assistant powered by GPT-5.4. Supports streaming responses, file uploads, and context-aware suggestions.

10.2 Auto-Triage & Assignment

AI analyzes incoming tickets and suggests: priority, category, assignee, and resolution. Configurable confidence thresholds determine auto-apply behavior.

10.3 Virtual Agent Phase 2

End-user-facing chatbot that can answer questions, search KB, and create tickets. Maintains session context for multi-turn conversations.

10.4 AI KB Generation Phase 2

Automatically generates knowledge articles from resolved incidents. Drafts go through review before publishing.

10.5 Change Risk Assessment Phase 1

AI evaluates change requests for risk level based on impact scope, timing, and historical data.

10.6 Recurring Detection Phase 1

Identifies recurring incident patterns and suggests problem records for root cause analysis.

10.7 Capacity Forecast Phase 2

AI forecasts future resource needs based on ticket trends, asset utilization, and growth patterns.

10.8 AI Learning Dashboard Phase 1

Track AI learning metrics, feedback trends, and model health. Submit corrections to improve accuracy over time.

14. Recycle Bin

Deleted items are soft-deleted and can be restored from the Recycle Bin. Available from the top-right menu. Permanently purge after review.

15. Engineer Review

AI-suggested actions queue for engineers. Review triage suggestions, auto-resolve candidates, and workflow recommendations. Accept or reject with one click.

16. Service Status Page Phase 3

Public-facing status page showing service health. Subscribers receive email notifications on status changes. Manage from Admin → Service Status.

17. Release Management Phase 3

Plan, track, and deploy releases. Link changes to releases. Track release status: Planning → Building → Testing → Deployed → Closed.

18. Self-Service Portal Phase 3

End-user portal with limited navigation (Self-Service, Knowledge, Catalog). Users can create tickets, browse catalog, search KB, and track their tickets.

19. Cost Allocation Phase 3

Track IT service costs by department, team, or service. Define cost rates, generate cost reports, and view allocation summaries.

20. Compliance & Audit Phase 3

Compliance evidence collection, export for SOC2/ISO audits. Full audit trail with integrity verification. See Security & Compliance Guide.

21. Contract Management Phase 3

Track vendor contracts with renewal dates, costs, and SLAs. Automatic alerts for expiring contracts (30/60/90 day warnings).

22. PWA & Offline Phase 5

Install VGC-ITSM as a Progressive Web App for native-like experience. PWA manifest available at /api/pwa/manifest.

23. Bulk Operations Phase 5

Select multiple tickets and perform bulk update (status, priority, assignee) or bulk close. CSV export for offline analysis.

24. Gamification Phase 2

Points awarded for resolving tickets, contributing KB articles, and meeting SLA targets. Leaderboard shows top performers. Accessible from Productivity module.

25. Setup Wizard v3.20

First-time setup flow for new deployments. Guides through company info, admin user creation, Entra ID configuration, PDPA settings, and branding customization. Accessible at first login when FEATURE_SETUP_WIZARD=true.

26. PDPA Compliance v3.20

Singapore Personal Data Protection Act compliance module. Manage consent purposes, data retention policies, and Data Subject Access Requests (DSAR). Configure via Admin Settings → PDPA when FEATURE_PDPA=true.

27. Customer Portal v3.20

White-label self-service portal for end users. Features: raise tickets, search knowledge base, track request status. Custom branding (logo, colors) via Branding Editor. Enable with FEATURE_PORTAL=true.

28. Billing v3.20

Per-user monthly billing with invoice generation. View billing entries, generate invoices for any period, and get cost summaries. Stripe-ready payment hooks. Enable with FEATURE_BILLING=true.

29. AI Governance v3.20

Control AI spending and automation levels from the Admin → AI Governance tab. Set monthly budget caps, choose autonomy level (assisted/semi/full), and review the AI audit log for all automated decisions.

30. Branding Editor v3.20

Customize the application appearance: logo, primary/accent colors, company name. Changes apply immediately to the portal and main app. Access from Admin → Branding tab.

31. FAQ

QuestionAnswer
How do I reset my password?SSO users: contact your IT admin. Local users: ask a VGC Dev Admin to reset via Admin Settings.
Can I use ITSM on mobile?Yes — the responsive UI works on tablets and phones. Install as PWA for best experience.
How does AI auto-triage work?AI analyzes ticket title, description, and context. It suggests priority, category, and assignee with a confidence score. Above 85% confidence, it auto-applies.
What happens to deleted tickets?They move to the Recycle Bin and can be restored. Permanent deletion requires admin action.
How do I connect Zendesk?Go to Admin Settings → Integrations → Zendesk. Enter subdomain and API token. See Integration Guide.
